# 学习路线

以下项目是待完成的练习计划，不代表已经掌握。

- [ ] 01 环境与第一个接口：启动服务，在 `/docs` 成功请求首页。
- [ ] 02 路径与查询参数：比较 `/items/1?q=book` 与 `/items/abc` 的响应。
- [ ] 03 请求体与校验：提交正确 JSON 和负数价格，解释 201 与 422。
- [ ] 04 响应模型与异常：使用 `response_model`，主动返回 404。
- [ ] 05 路由拆分：用 `APIRouter` 把用户与商品接口分开。
- [ ] 06 依赖注入：通过 `Depends` 复用分页参数。
- [ ] 07 数据持久化：加入 SQLite，实现增删改查，验证重启后数据仍在。
- [ ] 08 自动测试：覆盖正常请求、非法输入和资源不存在。
- [ ] 09 综合项目：实现待办清单 API，并写好启动和使用说明。

每完成一项，补充对应笔记和代码路径，再勾选。
